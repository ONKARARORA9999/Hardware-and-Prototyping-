# Hardware-and-Prototyping-
The Automated Street Light System is an energy-efficient prototype using an Arduino Microcontroller, a Light Dependent Resistor (LDR), and LEDs to simulate smart city infrastructure. It reduces power consumption by automatically turning street lights ON at dusk and OFF at dawn based on ambient light
The Arduino microcontroller reads this sensor data in darkness, high resistance triggers the Arduino to turn the LEDs ON, and in daylight, low resistance turns them OFF
